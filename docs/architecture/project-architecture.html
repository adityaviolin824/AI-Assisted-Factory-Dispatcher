CURRENT means prototype behavior.

Mixed labels describe an integration boundary.

LangGraph controls workflow progress. Python validates and calculates. A preview becomes an assignment only through the planned commit service.

Deterministic allocation

Capability, permission and capacity checks, deadline feasibility, calculated rankings and tentative queue updates.

Mermaid source
flowchart TB
    NODE["LangGraph plan_allocation - CURRENT<br/>Invoke deterministic Python; no LLM choice or arithmetic"]
    LOAD["Use same-run state or an explicitly named saved run<br/>Plan current verified tasks; account for missing outcomes<br/>Label an incomplete processing run as partial"]
    SORT["Plan earliest deadline first - CURRENT modules<br/>Equal deadlines retain source order<br/>Begin with a copy of the starting workshop queues"]
    NEXT["Take next task using the evolving tentative queues"]
    TASK{"Supported ready allocation task?"}
    INFO["Information question or unsupported intent<br/>Record outcome; do not allocate"]
    REVIEW["Review or clarification<br/>Missing facts, duplicate order requests,<br/>unsupported split/condition or failed verification<br/>No queue reservation"]
    subgraph RULES["PYTHON CHECKS - Factory Primer's three workshop questions"]
        ALLOWED["Are they allowed to?<br/>Active status, batch cap,<br/>requested destination and exclusions"]
        CANMAKE["Can they make it?<br/>Product category matches workshop capability"]
        TAKE["Can they take it now?<br/>Current queue and capacity<br/>Production, expected rework and pickup lead<br/>Deterministic completion and deadline checks"]
        COST["Calculate comparison values in code<br/>Cost, defect rate, delivery time,<br/>lateness and workload concentration where relevant"]
        ALLOWED --> CANMAKE --> TAKE --> COST
    end
    FEASIBLE{"Allowed on-time candidate exists?"}
    NOOPTION["Record feasibility review<br/>Show deterministic rejection reasons<br/>Closest late option or unrestricted alternative is information only"]
    RANK["Rank feasible candidates in code<br/>Default: delivery time then cost<br/>Cheapest or quality-first when requested<br/>Policy experiments remain separate; no invented weights"]
    ROLE{"Winning workshop's recorded role is clear?"}
    ROLEREVIEW["Ambiguous reference-only winner<br/>Request dispatcher review<br/>No silent destination substitution"]
    RESERVE["Build recommendation and reserve tentative queue time<br/>Add production and expected rework to the queue copy<br/>Pickup transport is outside production occupancy"]
    RECORD["Save a decision row<br/>Selected option, candidate/rejection evidence,<br/>precomputed metrics, policy and input snapshots"]
    REMAIN{"More tasks?"}
    WARN["Compute related-review warnings without changing selection<br/>Warned summary rows become provisional<br/>Recommended work still reserves tentative queue time"]
    PLAN[("Saved plan and timestamped history - CURRENT<br/>Decisions, provisional summaries and review_warnings<br/>Processing completeness, missing outcomes and queue copies")]
    CONSOLE["PLANNED dispatcher console<br/>Inspect evidence, alternatives and calculated trade-offs"]
    COMMIT["PLANNED live confirmation and atomic commit<br/>Recheck current task, order and queue state<br/>Persistent assignments are a separate workflow"]
    CURRENT[("CURRENT controlled snapshot<br/>Order/workshop CSVs and initial queues")]
    LIVE[("PLANNED live operational state<br/>Current order status, active assignments,<br/>remaining work and committed queue reservations")]
